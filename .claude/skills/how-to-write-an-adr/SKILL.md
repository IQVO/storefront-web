# Write an ADR

Files are `docs/adr/NNNN-kebab-title.md`, next number after the highest. Format: `# N. Title`, `Status:` line with design source, `## Context`, `## Decision` (bullets; assumptions as **A1**, **A2**), `## Consequences`. Update the ADR that a change contradicts instead of leaving it stale. Brand-neutral wording only.
